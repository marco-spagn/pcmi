# STIX 2.1 Example Bundles

This directory contains example STIX 2.1 bundles generated by TI Mindmap HUB.

## Examples

| File | Description |
|------|-------------|
| [`example-apt-campaign.json`](example-apt-campaign.json) | Complete example showing a typical APT campaign bundle with threat actor, malware, indicators, attack patterns, and relationships |

## Bundle Structure

Each bundle follows this general structure:

```
Bundle
├── Report (SDO) — Main container
├── Threat Actor(s) (SDO)
├── Malware (SDO)
├── Indicator(s) (SDO) — IOCs
├── Attack Pattern(s) (SDO) — TTPs
├── Vulnerability (SDO) — CVEs
└── Relationship(s) (SRO)
```

## Validation

All examples have been validated against:
- STIX 2.1 JSON Schema
- [cti-stix2-validator](https://github.com/oasis-open/cti-stix2-validator)

## Usage

### Python (stix2 library)

```python
from stix2 import parse

with open('example-apt-campaign.json', 'r') as f:
    bundle = parse(f.read())

for obj in bundle.objects:
    print(f"{obj.type}: {obj.get('name', obj.id)}")
```

### Command Line Validation

```bash
pip install stix2-validator
stix2_validator example-apt-campaign.json
```

## Notes

- All IOCs in examples are fake/sanitized
- Examples use RFC 5737 documentation IP ranges (192.0.2.x, 198.51.100.x, 203.0.113.x)
- UUIDs are randomly generated examples
